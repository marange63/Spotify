Good morning, and welcome to Cautious Optimism Briefings for Sunday, October 4, 2026. This is the AI products briefing.

The last few days on this beat were about OpenAI's DevDay products. Today turns to two launches this show has not touched yet, one from Google and one from IBM, plus a rollout from Anthropic. A quick sourcing note. The Google pricing and access terms come from Google's own release post. The IBM and Anthropic details come from secondary reporting, and I will flag the weaker claims as we go.

Our lead is Google's Gemini 4 Argon, and the most important change is the output ceiling. Google says it is significantly expanding the model's output token limit to an industry-leading one million tokens. Reporting puts the prior limit at 64,000. That is roughly a sixteen-fold increase in what a single agent run can hand back.

For a builder, that is the difference between an agent that returns a fragment and one that returns a finished artifact. Our inference is that this matters most for code migration and document generation. Those products today chunk the work into pieces and stitch the results back together. A single run that can finish the job changes that architecture. It also weakens the case for orchestration products whose main job is managing the chunking.

There is one capability number worth hearing. AI Weekly relays a Google figure of 77.9 percent on DeepSWE version 1.1, a long-horizon software engineering benchmark. That is a vendor number, and nobody has independently tested it. Treat it as a direction, not a verdict.

Now the rollout order, which matters as much as the spec. Argon is going first to trusted cyber defenders through what Google calls its Fairwind Program. Paid API customers and Google AI Ultra subscribers come after that. Google gives no date for either group, and it does not say why defenders go first. Any explanation is ours, not Google's. The plausible reading is that security is where Google wants a long-running agent proven first. That fits a pattern on this beat. On October 2, we covered OpenAI shipping Codex Security Cloud, an unattended security reviewer. Security keeps turning up as the first commercial home for agent products. The practical consequence for now is simple. Most developers cannot use Argon yet.

Then there is price. Google's introductory API pricing is $2 per million input tokens and $10 per million output tokens, with cached input priced at 95 percent off. After the introductory period, the price rises to $4 and $20. Google gives no end date for the introductory window.

Here is our arithmetic from those list prices, not a Google figure. A run that fills the full million output tokens costs about $10 at the introductory rate. After the step-up, the same run costs about $20.

That two-and-ten price should sound familiar. It is the list price of OpenAI's GPT-6.1 Sol, which we covered on September 30. One new detail on Sol comes from The Next Web, which puts cached input at 10 cents per million tokens. And Sol launched in the API, ChatGPT Work and Codex, not in the main ChatGPT chat.

The bigger point is the pattern. On September 30, we covered OpenAI halving the included usage on its two-hundred-dollar Pro plan. On October 2, it was GitHub putting Sol straight onto usage-based billing. Now Google has set a launch price it has already said will double. The sticker is temporary, and the terms keep moving. Anyone modeling margins on Argon's introductory rate is pricing against a number with an expiry date nobody has disclosed.

The second problem is review. A million-token output is cheap to generate and expensive to check. On October 2, this show argued that unattended coding tasks move the bottleneck from generation to review capacity. Long single-run outputs tighten that constraint. They extend it from code to every long-form agent deliverable, from reports to migrations.

So Argon changes what one run produces. The next story changes where that run is allowed to happen.

On October 1, IBM introduced a self-hosted version of Bob, its AI development platform. Enterprises can run the full coding and modernization system on-premises, or fully air-gapped. According to Startup Fortune, the target is banks, governments, and other regulated industries that have been unwilling to send proprietary source code to a third-party AI cloud. That has been the central objection in regulated accounts, and this option removes it. To be clear, this is a change in deployment, not a new capability.

IBM's supporting numbers come with caveats. More than 80,000 IBM employees now use Bob. Surveyed users report an average 45 percent productivity gain across modernization, security, and new development work. Both figures are IBM's own. The 80,000 are IBM staff, not paying customers, so that is dogfooding scale, not market adoption. And the 45 percent is a self-reported survey, not a measured output.

Startup Fortune also reports that the self-hosted version supports Nvidia's Nemotron and Poolside's Laguna, with hybrid setups available. That is a single-source claim, so hold it loosely.

Several things are missing. IBM has not disclosed a price for the self-hosted tier. No external bank or government customer is named. And the customer, not IBM, now carries the inference hardware and the operating cost. Our inference is that this may erase part of the appeal for smaller buyers.

Now set IBM against the containment stories from last week. On September 29, Nvidia's Sentry was a runtime watchdog sold as a reference design. On September 30, HPE's integration with Nvidia's runtime was a plan with no date. IBM's version is a shipped option, and it contains code by physical location rather than by monitoring. That is the first form of containment a regulated buyer can actually deploy.

The second-order effect is our inference. Cloud-only coding tools lose their default position in regulated accounts once a major vendor offers an air-gapped alternative. And mainframe modernization, which is IBM's home turf, may drift toward on-premises AI. The takeaway is that regulated code can now stay inside the building. What we have not seen yet is a bank named as a buyer.

That leads to the last item, which is about the delivery format. What an agent run hands back is increasingly a file you already know how to open.

On September 16, Anthropic announced that Claude Cowork and Claude chat are merging into one experience. I should disclose that Anthropic makes the model behind this show. In the merged version there is no mode to choose. Claude decides whether a request needs a quick answer or finished work, such as research, a report, a spreadsheet, or a presentation. Claude Docs and Claude Slides launch in beta. Pro and Max users get the update first, over the coming weeks. Progress by tier is not verified as of today, so treat this as a staged rollout, not a finished launch.

The files are the substance here. Anthropic describes spreadsheets with working formulas, and presentations that open in PowerPoint. But opening in PowerPoint is a compatibility claim. Fidelity and collaboration are the real test. On September 30, we described OpenAI's bet on pulling work inside its own agent. Claude is now pulling office-file work inward too. The upshot is that competition with office suites shifts from generating files to editing them well.

One more term to note. The Neuron, an AI newsletter, reports a 50 percent discount on session limits for Pro, Max, and Team, running through October 15. We have not checked that against Anthropic's own pricing pages. It is one more time-limited usage term, the same pattern as Argon's introductory rate.

So what ties these three together? It is not raw capability. It is delivery and placement. Argon sets the size of what an agent returns. IBM sets where that agent is allowed to run. Claude sets the format the work lands in.

Three things to watch. First, when Argon opens to paid API users, and when the two-and-ten introductory rate ends. Second, whether IBM names an external customer for the self-hosted Bob. Third, whether anyone independently tests a single-run output of this length. Until those answers arrive, treat the headline numbers as claims.
