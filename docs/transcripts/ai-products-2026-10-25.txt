Good morning. It's Sunday, October 25th, 2026, and this is your AI products briefing.

One disclosure up front: Anthropic makes the model behind this show, and one item today touches Claude's placement inside a rival's tools. The thread running through this week's new moves isn't capability. It's distribution, and who pays for it.

Start with OpenAI. On October 21st, OpenAI expanded ChatGPT Ads to 26 more countries, bringing total coverage to 89 markets. That's not a cautious pilot. Adding two dozen markets in a single move, rather than testing them one at a time, is a scale decision. OpenAI also disclosed that more than 100,000 advertisers have run campaigns on ChatGPT in the just over eight months since ads launched.

That number matters for a specific reason. Episode after episode in recent weeks, this beat has closed on the same note: launches, but no usage data. This is a real adoption figure that OpenAI has put its own name to. So it partly breaks that pattern, and it's worth saying so.

But bound it carefully. A hundred thousand advertisers is a cumulative count of everyone who has ever run a campaign over eight months. It includes one-off tests during the launch period. It says nothing about how many are still spending, how much they spend, or what OpenAI earns. No revenue, ad-spend, or active-advertiser figure accompanies the announcement. And no outlet, including trade press that watches OpenAI's ad business closely, has reported one. Coverage of the expansion explicitly describes the count as cumulative, not a measure of current activity. So treat it as reach, not receipts.

One more detail needs a flag. Secondary coverage consistently reports that ads appear only on the Free and Go plans, with Plus, Pro, and Enterprise staying ad-free. I couldn't confirm that split against OpenAI's own wording, so hold it as likely rather than settled. If it holds, ChatGPT's free tier is becoming ad inventory, and the paid tiers become the ad-free product.

Here's the second-order read, and it's my inference rather than anything in the data. Ads inside a conversational assistant compete for the same budgets that go to search marketing today. Those are high-intent queries. A user asking ChatGPT which running shoe to buy is exactly the moment a search advertiser pays for. There's no spend-shift evidence yet. But a hundred thousand advertisers testing the format is the precondition for that shift. The bottom line: OpenAI's consumer reach now has a business model attached, with at least one disclosed number behind it.

OpenAI is monetizing reach it already has. Google, by contrast, is paying to buy reach inside tools developers already use.

Gemini 4 Argon went generally available in the Gemini API on October 13th. Google describes its context as an industry-leading one million token limit. Note the word Google uses, though: unified. Input and output draw on the same one-million budget. So a long agentic generation eats into the context you can feed in. For a developer loading a large codebase and asking for a long refactor, that budget gets tight faster than the headline suggests. It's a design trade-off, not just a big number.

The launch API price is two dollars per million input tokens and ten dollars per million output tokens. That's cheap access now, while developers are still deciding which model to default to. It's a classic land-grab move.

The same day, GitHub added Argon to Copilot's model picker for paid subscribers: Pro-plus, Max, Business, and Enterprise. It sits across the major IDEs and the Copilot command line. Free Copilot users don't get it. That placement is the real story. A frontier-class model now sits in the picker developers already open every day, inside a tool Microsoft owns. Google doesn't have to convince anyone to visit a destination of its own.

Google backs this with its own number. It says Argon helped teams in its coding product, Antigravity, increase agentic code submissions by more than 35 percent. Treat that skeptically. It's Google measuring Google's own product. And it counts submissions, not code that got merged or survived review. More submissions can just as easily mean more work for reviewers downstream.

GitHub's claim deserves the same scrutiny. GitHub says Argon solved more tasks than previous Gemini models on every coding benchmark, with its largest gains in Copilot CLI. That compares Argon only against Google's own prior generation, not against rival models. So it tells a developer nothing about whether to switch. And a slot in the picker is availability, not usage. Neither Google nor GitHub has published adoption figures.

Now the callback. On October 16th we covered Claude appearing in the Gemini Enterprise model selector. Yesterday we covered Claude arriving inside Antigravity, Google's own coding tooling. Now Google's Argon sits inside Microsoft's GitHub Copilot. The pattern runs both directions.

My inference from that is this. Once a model is one entry in somebody else's paid-tier dropdown, the model vendor competes on price inside another company's storefront. A low launch price is the lever Google just pulled. Meanwhile, whoever controls the picker and the billing collects the seat revenue regardless of which model wins. The takeaway: Gemini 4 Argon is a strong model, but this week's news is where it's placed and what it costs to try, not what it uniquely does.

And Microsoft is running that same shelf logic on its own documents. A quick correction first. Yesterday we aired Microsoft's Copilot for Legal as context we couldn't confirm was new. Microsoft's own post settles it: rollout began October 15th, so this is a clarification, not this week's news.

More than 20 legal skills are now generally available inside Microsoft 365 Copilot. They're delivered through two Microsoft-built plugins, one in Word and one in Cowork. The Word plugin replaces an earlier feature called Legal Agent, so part of this is repackaging existing capability. What's genuinely structural is the plugin registry. Partner-built legal plugins are beginning to roll out through it. That means outside legal-AI vendors get distribution inside Word, rather than competing against it head-on. No adoption or customer figures have been disclosed.

My inference on the consequence: a standalone contract-review tool without a slot in that registry now has to justify a separate login against software already open on every lawyer's desk. Vendors who partner gain distribution. Vendors who don't are likely to lose pricing power. So what: Word is becoming a shelf that specialist vendors rent space on, the same logic GitHub is running with Argon.

Pulling the three threads together. OpenAI is monetizing the reach it already has, through ads. Google is buying reach in developer tools, through price and picker placement. And Microsoft is turning its own surfaces, GitHub and Word, into shelves that rivals and specialists rent rather than own. None of this is about which model is smartest this week. It's about who controls distribution, and who collects the toll.

Three things to watch. First, Gemini 4 Argon is set to become the default model inside Gemini Enterprise this Tuesday, October 27th. It's the catalyst this beat has carried since the 16th, and it tests whether defaults decide what employees actually use. Second, whether OpenAI ever discloses ad revenue, or an active-advertiser count rather than a cumulative one. Third, any real usage data for Argon inside GitHub Copilot or the Gemini API.
