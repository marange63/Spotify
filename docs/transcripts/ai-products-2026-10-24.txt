Good morning. It's Saturday, October 24th, and this is your AI products briefing. One disclosure up front: Anthropic makes the model behind this show, and two items today touch Anthropic's models or standards.

This week the agent question stopped being about which model you use. It started being about where the agent actually runs, and under whose name. Three answers surfaced in the last few days: on your own machine, under an enterprise identity, or inside a rival's tool. Let's take them in that order.

Start with the lead: Perplexity's Computer agent can now run fully on-device on a Mac. Perplexity's own announcement, posted October 20th, says the AI model, the harness, and the task execution all run entirely on device. It's available to Pro, Max, and Enterprise subscribers. Users run one of two local models: Qwen 3.6, or PPLX Pro, which Perplexity describes as a post-trained version of Qwen. Perplexity recommends an Apple silicon Mac with 36 gigabytes or more of unified memory for the best experience. That's a recommendation, not a hard floor.

That 36-gigabyte figure is worth setting against one from earlier this week, with a caveat up front. On Tuesday we covered Meta's Muse Spark Open, released October 15th. It's a different class of model, and Perplexity hasn't disclosed the size of its local model at all. Still, running Meta's model on the desktop took two Mac Studios, each with up to 512 gigabytes of memory, and even then only as a heavily quantized copy. Perplexity's local mode asks for 36 gigabytes, which is a high-end laptop configuration. So the point isn't that frontier capability has shrunk onto a laptop. It's that a local agent is now packaged as a subscription feature, rather than a workstation project.

It's also a break from this week's pattern. Nearly everything else we've covered ran in someone else's cloud. Anthropic's Duet, its new proactive agent app, keeps working from a cloud VM. Cursor's coding agents lean on cloud environments. Perplexity's local mode is the first this week to pull the agent back onto the user's own hardware.

Why does that matter practically? Document workflows that compliance teams have kept away from cloud AI entirely become plausible agent territory. Think legal review, clinical notes, and financial files, where the data now doesn't have to leave the laptop. That's a genuine capability unlock, not a rebrand. There's a hardware consequence too, and this is my inference. If the useful agent needs 36 gigabytes of memory, laptop refresh specs start to gate which agents a firm can run locally. Memory becomes a procurement line for agent software, not just the licence.

But be careful with how far that goes. Perplexity has published nothing on how the local model's speed or quality compares with its cloud-hosted version. That trade-off isn't under-reported; it's simply undisclosed. And the cloud is still in the loop. Users can authorize Computer to escalate to the cloud for current information, browser use, and connected apps. Perplexity's post says the choice of where tasks run is, in its words, "completely in the user's hand."

That's a per-user toggle, not an enforceable enterprise policy. A compliance officer wants an admin switch that forces local-only processing across a whole team. What's documented here is an individual clicking approve, task by task. Perplexity's existing admin controls belong to an older hybrid product, not this fully local mode, so for now there is no documented admin switch for it. The memory recommendation adds a second limit. My read is that many enterprise-issued laptops sit below 36 gigabytes, which would narrow the fleet that can use it. So this is a privacy default inside a hybrid architecture, not a fully audited enterprise product yet. The so-what: privacy-bound document work is now addressable by an agent, at a capability cost nobody has measured.

The same sensitive-document buyer is being courted from the opposite direction. This time it's the incumbent whose software already holds the documents. And the more interesting move there is about identity. According to a Microsoft partner's weekly roundup, Copilot Studio is previewing persistent identities for agents. That means dedicated credentials, workflow memory, and automated triggers. An agent becomes a named principal that IT can scope and revoke, not just something that answers a prompt.

That fits a ladder this beat has been tracking. Earlier this month, governance meant after-the-fact audit tools. This past week it meant pre-action gates, like Duet checking with the user before it sends or pays, and Walmart's promised spending caps for shopping agents. Agents with their own enterprise identity would be the next rung. It also connects back to the lead, and this is my inference. An identity is exactly the handle a compliance team needs to enforce policy on an agent. That's the piece Perplexity's local mode doesn't yet offer. Worth flagging, not yet worth trusting, though: it's a preview, it comes from a single secondary source, and there are no adoption figures attached.

The same roundup reports that Copilot for Legal has reached worldwide general availability, with more than twenty purpose-built legal skills and partner plugins working inside Word. We couldn't confirm with Microsoft that this is new this week, so treat it as context, not news. Its edge is simply that the document never has to leave Word. My inference is that standalone legal-AI vendors now have to win on accuracy and research depth, not on access to the document.

If the device and the tenant are two answers to where an agent runs, the third is inside someone else's product entirely. According to Google Cloud's blog, Claude Opus 5.5 and Claude Sonnet 5.5 are now available inside Antigravity, Google's own coding-agent tooling. On October 16th we covered Claude appearing as an admin-enabled option in the Gemini Enterprise model selector. We asked then whether that reach would extend beyond the selector. Antigravity is a partial answer, in developer tools rather than workflow agents. This is availability, not adoption; there are no usage figures.

That pairs with a number we held back yesterday on Anthropic's Agent Skills standard, because we couldn't confirm it. Anthropic's own announcement, donating the standard to the Linux Foundation's Agentic AI Foundation, now gives the count. It says more than seventy agent platforms, including ChatGPT, Cursor, GitHub Copilot, and VS Code, have integrated the format. That's Anthropic's own count, not independently audited. And "integrated" isn't defined, so it could mean full support or a thin parser. The security-review question for third-party skills that we raised yesterday is also still unanswered. But directionally it fits. The model is becoming a swappable input even inside a competitor's coding tool. And the packaged task knowledge an agent carries is reportedly portable across dozens of platforms. Switching cost isn't disappearing. It's moving up, into the IDE, the workflow, and the connector layer around the model.

So, three placements: the laptop, the tenant, and the rival's tool. Each one is a real option a buyer can choose today, and none has usage data behind it yet.

Three things worth watching from here. First, whether anyone publishes a real capability or latency comparison for Perplexity's local mode. Alongside that, whether Perplexity extends an admin control to the local mode, so a firm can actually require it. Second, whether Microsoft moves the agent-identity preview toward general availability, or puts customer numbers behind Copilot for Legal. And third, next Tuesday, October 27th. That's when Google's own flagship model, Gemini 4 Argon, is set to switch on by default inside Gemini Enterprise, while Claude still waits for an admin to opt in. It's the catalyst this beat has been carrying since the 16th, because it tests whether defaults, rather than availability, decide what employees actually use.
