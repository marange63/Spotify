Good morning, and welcome to Cautious Optimism Briefings. It's Monday, August 24th, 2026.

For a week this show has argued that the product frontier in AI has moved below the model — into plumbing, governance, and permission. We've made that case on routing and billing, on protocol plumbing, on data governance, on the agent's acting layer, on monetization, and on identity. Always as a directional claim. Never with a number attached. Today, for the first time, somebody put a number on what that layer is worth.

On August 21st, Nvidia published research on its developer blog showing that its own agent system, called AVO, scored a perfect 100.00 on the ARC-AGI-3 public benchmark set — all 183 levels, across 25 environments. Nvidia's own text says that run used Claude Opus 5. That matters because of the comparison Nvidia then draws. ARC Prize, the independent group that runs the benchmark, separately reports that same model, at high reasoning effort, scoring roughly 30 percent on its own. Same model. Same underlying intelligence. The gap between 30 percent and a perfect score is not the model. It's everything Nvidia wrapped around it.

So what did Nvidia wrap around it? Two things, in the company's own words. The first is persistent memory that, quote, carries forward prior implementations, evaluation results, compiler and profiler outputs, and accumulated reasoning — so the system doesn't restart from zero on every attempt. The second is a supervisor process that, quote, monitors the broader trajectory for stagnation or repeated unproductive cycles, and can redirect the main agent toward alternative strategies when needed. Memory, plus a watchdog that intervenes. That's the whole trick. Nvidia also reports AVO cleared the set in 6,624 environment actions, about 12 percent fewer than the prior leader, a system called VISTA, needed for the same 183 levels. So the harness isn't only more accurate. It's leaner in steps per solved task.

Here's why that reframes the buying decision for anyone deploying agents commercially. If the harness is doing most of the work, then engineering time spent on memory management and stall detection may buy more reliability than paying up for a more expensive frontier model. That's a real shift in where enterprise AI budgets should point — and it's an implication this result supports, not a proven enterprise outcome. There's a quieter casualty too, and it's the model-only leaderboard score. If wrapping the same model in a better harness moves it 70 points, then a score attached to a model in isolation stops predicting how that model behaves as a deployed agent. Anyone procuring on leaderboard rank alone is measuring the wrong variable.

Now the skeptical turn. Nvidia is close to the least neutral messenger possible for the argument that scaffolding beats model spend. A harness that replays memory, re-runs evaluations, and supervises a stalling agent burns far more inference per completed task than a single model call does. Spend on the harness, not the model, is — for the company selling the GPUs those extra passes run on — also an argument for buying more compute. Second, Nvidia scopes the result itself. In its own words, these are, quote, not results on the semi-private or fully private competition sets. A perfect score on a public set that a team can iterate against is a materially weaker claim than the same score held out. Third, there is no code, no weights, and no API for AVO — only the blog post and an arXiv paper — and the post says nothing at all about whether any of that will ever be released. Nobody outside Nvidia has reproduced this. Treat it as demonstrated once, by its own author, not as a capability anyone can currently buy.

If the value is migrating into the harness, the next question is who controls how a harness gets packaged and shipped. That answer arrived earlier this month.

On August 12th, GitHub shipped general availability of Agent Plugins 1.0 across VS Code, Copilot CLI, the Copilot app, and the Copilot SDK. The format itself was co-published by AWS, Cursor's parent Anysphere, Microsoft, OpenAI, and Vercel, with Google reported to have joined as a core maintainer. It packages an agent's skills together with its MCP server connections into one installable plugin that any compatible client can pick up. In practice that means a tool builder stops repackaging the same integration separately for ChatGPT, Copilot, and Cursor.

The line that matters isn't the feature list. It's the governance. The standard is, in GitHub's words, quote, governed independently of any single vendor. That's what makes a format expensive to defect from — five or six platform vendors gave up the right to change it unilaterally. Be clear on the age, though. This shipped twelve days ago, not this week. And no count exists of third-party developers who have actually published a plugin package, so what we have is a supply-side commitment from platforms, not evidence that developers have moved. One absence is worth watching: Anthropic, which created the MCP protocol this format wraps, is not on the publisher list. That's reported, not confirmed against a statement from either side. The takeaway is that distribution of agent skills is being commoditized by committee, before any single vendor could corner it.

Standards decide who distributes the parts. The money question is who assembles them and sells the result — and on August 20th, an incumbent answered. Thomson Reuters shipped general availability of the next generation of CoCounsel Legal, built on Anthropic's Claude Agent SDK plus its own in-house model, and grounded in Westlaw and Practical Law content. It's the pattern we flagged yesterday with Slack Code, which launched hosting four rival coding agents rather than picking one: the lab supplies the agent, and somebody else owns the surface and the customer relationship. Thomson Reuters says the system is built to, quote, plan, reason, and execute at the level of a senior associate. One new feature, Tabular Analysis, is described as reviewing, quote, up to 10,000 documents with up to 100 questions, in a single pass.

Run that through the replace-versus-augment test. A tool that goes from legal research straight to a first-draft brief isn't speeding up a lawyer's search. It's aimed at first-pass work itself, which is the base of the law-firm leverage pyramid. If it performs as described, that compresses billable junior-associate research hours, with real consequences for how early-career legal work gets staffed and priced. But hold the marketing at arm's length. Senior-associate level is Thomson Reuters' own qualitative claim, with no measured comparison against work an actual associate produced. The headline number — one million professionals across 107 countries relying on CoCounsel — is the installed base of the whole product line built up over years, not adoption of an agentic release that shipped four days ago. No pricing was disclosed. And this is a United States launch first, with Canada, the UK, and Australia expected later this year.

Pull the thread together. Performance is moving into the harness. The harness format is already being standardized out from under every vendor that helped write it. So the durable margin doesn't sit with the model, and it doesn't sit with the packaging. It sits with whoever owns proprietary content and the workflow wrapped around it — which is exactly the position Thomson Reuters is defending, and exactly the position the labs are renting space inside.

One note on sourcing, and for once it's a partial break rather than the usual complaint. For more than a week, every load-bearing figure on this show has been a vendor measuring itself. Today's lead is different. The 30 percent baseline is ARC Prize's own published number rather than one Nvidia generated, though it reaches us through Nvidia's citation of it. That's a real improvement. It's still partial. Nvidia ran the test, and Nvidia hasn't released the code for anyone else to check it.
