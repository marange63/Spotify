AI Products & Applications

Transcript · September 10, 2026

Good morning, it's September 10th, and this is your AI products briefing.

For the past week, this beat has revolved around a single question: who is allowed to use a model. Trusted-access programs and vetting tiers on one side. Deliberate giveaways on the other. Today, not one item in the news turns on access at all. The story has moved to the plumbing wrapped around the model. And one vendor just killed its own flagship developer product to try to own that plumbing.

Start with Perplexity. The company is retiring Sonar, the search API that made its name with developers. In its place is something it calls the Agent API. That is a single endpoint bundling web search, URL fetching, code execution, and connections to outside tools and services over MCP. The retirement is real, and it is dated. Perplexity's own developer forum says Sonar endpoints are, in the company's words, "fully available today and retire on September 27." That is not a vague sunset window. It is a hard deadline, and Perplexity has published a migration guide pointing Sonar customers at the new endpoint. One note on sourcing: that language comes from Perplexity's own company-run channel, not from the third-party aggregators that first carried this story.

Here is why it is more than an API refresh. Search used to be a product you could buy on its own. You bought an endpoint, it returned results, and that was the whole relationship. Perplexity is now saying retrieval is one tool call inside a larger runtime. That runtime also executes code and orchestrates other tools. And every existing customer has to adopt it, whether they wanted the extra machinery or not. The bet is that the category itself changed shape. It went from selling an API that returns good search results to selling the harness an agent lives inside. For the search-infrastructure startups whose entire product surface is one endpoint, that is the uncomfortable read. If retrieval is a tool call, result quality on its own stops being a business.

It is also a direct challenge to something this beat has argued three times in five days. Our read has been that provider-abstraction layers gain value as models churn underneath them. Perplexity is the first vendor to move against that read. It is not abstracting across the layer. It is trying to absorb the layer into one proprietary endpoint.

Pricing is where the bet gets harder to evaluate. Sonar billed a flat rate you could quote and compare. The Agent API does not. Perplexity's pricing documentation charges a base model token rate, then meters each tool separately, per invocation. A web search call runs about a quarter of a cent. A code-execution sandbox session runs three cents, inside a roughly twenty-minute billing window. So the figures do exist. The early reporting that Perplexity had shipped an agent bundle with no disclosed pricing was simply wrong. But additive, per-tool metering is a different thing to reason about than one headline rate. No source supplies a realistic tool mix, so nobody can turn that rate card into a single cost-per-task comparison against Sonar. One more caveat. Whether the Agent API is formally generally available, or still mid-rollout, is not settled in Perplexity's own language. Treat it as a live release, not a confirmed GA product.

Now the counter-case, because bundling is not automatically a win. Consider the developer who wanted a search endpoint and now has to price out a multi-tool runtime. The rational response is to shop. Exa, Tavily and Brave's Search API can each advertise one simple, predictable rate. Cost predictability itself becomes the competitive lever the moment Perplexity's costs get harder to estimate up front. And a vendor that retires a working, simple product and forces migration is usually consolidating because the standalone version was not paying for itself. It is rarely responding to customers asking for a bundle. So the honest takeaway is two-sided. Perplexity has made a real structural bet on owning the agent runtime, and it has handed competitors an opening, on both migration friction and pricing clarity, that did not exist a month ago.

That kind of runtime only pencils out if the tool calls inside it get cheap. That is the second story, and it is about price rather than capability. Anthropic released Claude Fable 5.1 at the start of the month. The number worth knowing is not a benchmark score. It is the cost cut. Anthropic says Fable 5.1 will cost, quote, an estimated 25% less than Fable 5 for typical workloads. For highly agentic work, it puts the savings at up to approximately 45%. Read that carefully. Those are Anthropic's own estimated savings, not a rate-card change anyone outside the company can verify. And a cut concentrated on agentic workloads is a subsidy for one architecture, not a general price reduction. It only lands if your workload is already shaped the way the vendor wants it shaped. Still, the direction is the point. A model that calls tools dozens of times per task only becomes affordable at volume once repeated-context pricing falls that far. Put the two stories side by side and you get the mechanism behind this week's news. Agent runtimes are being productized at the exact moment the token economics of many-tool-call workflows stopped being prohibitive. That is a precondition, not a coincidence.

There is a consequence worth naming. When the cost structure rewards long, tool-using loops, application architecture drifts toward those loops. And the scarce thing stops being model choice. It becomes knowing what your agent actually did across forty tool calls, and whether it did any of it correctly. That pushes value toward observability and evaluation tooling, and away from model-selection work.

The same absorption is happening at the enterprise end, slower and less visible. Microsoft's September Copilot release wave is pushing natural-language querying of Dataverse data toward general availability. In the words of the Microsoft-ecosystem blog carrying the release notes, it "will be generally available in September, allowing users to ask about their Dataverse data and get grounded answers without leaving Copilot." Microsoft's own release notes could not be checked directly for this briefing, so take that wording as reported rather than official. Copilot is also picking up the ability to create and query Planner tasks. And multimodal capture is rolling out on Android, so meetings, audio notes and images get turned into structured notes inside Copilot Notebooks automatically.

None of that is dramatic on its own. Stack it up and Copilot is absorbing surface area that used to require separate tools. A BI dashboard for a quick lookup. A meeting-notes app. A lightweight task manager. But be precise about the ceiling. Natural-language query removes a reason to open a dashboard for a simple lookup. It does not touch the BI platform underneath. And Microsoft has published no adoption figures for any of these features. So what you are watching is surface area captured, not usage won. The release-wave language is directional too. Rolling out in September, with no committed calendar date, from a company whose features have a long history of sitting in staged rollout for months.

One short beat in the same vein. ElevenLabs has made a feature called Procedures generally available for its voice agents. These are task-specific instructions with their own triggers, so a single voice agent can handle several distinct jobs. The alternative was cramming every instruction into one enormous system prompt. No primary changelog was verified here, and no figures attach to it, so treat it as a reported release. But the shape is identical to everything else this week. Logic is moving out of a monolithic prompt and into a structured, triggered runtime. This time in voice rather than in search or productivity software.

So here is the throughline. On the 7th, and again on the 9th, this beat argued that differentiation was migrating out of the model and into the harness around it. The routing, the evaluation, the tool orchestration. This week that harness stopped being an argument and started being sold as a product, in three separate places at once. Two disclosures would settle how real Perplexity's version of it is. A genuine per-task cost comparison against Sonar. And a confirmed general-availability status rather than a rolling release. Watch for both.

That's the briefing for September 10th. Talk to you tomorrow.
